Three-Role Platform Ecosystem

Engineered with role-based access control (RBAC) connecting citizens, municipal authorities, and system administrators.

👤

1. Citizen User

Citizens capture road damage photos, receive instant AI severity scores, submit public grievances, upvote community reports, and track repair status in real-time.

Try Citizen Demo →
🏛️

2. Government Official

Municipal Public Works Department (PWD) officials manage the municipal ticket queue, update ticket states (Pending ➔ In Progress ➔ Resolved), and leave official verified responses tagged with [Govt Official].

Try Govt Dashboard →
⚙️

3. System Administrator

System admins monitor deep learning vision model health, telemetry, user account permissions, database performance, and platform security tagged with [System Admin].
